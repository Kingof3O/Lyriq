# Lyriq Brand Assets

## Core idea
Lyriq is a premium lyrics-first desktop companion centered on synchronized lyrics, translation, and language understanding.

## Logo concept
Three horizontal lyric lines intersected by a vertical playhead/cursor. The mark represents live lyric timing, reading, translation layers, and synchronized playback.

## Primary palette
- Obsidian: #09090B
- Carbon: #131316
- Pearl: #F7F7F8
- Mist Gray: #A1A1AA
- Electric Violet: #8B5CF6
- Soft Violet: #A78BFA

## Suggested tagline
Hear it. Read it. Understand it.

## Recommended usage
- Primary horizontal logo: website header, installer, about screen, README
- Stacked logo: splash screens, social avatars with text, presentations
- Symbol-only: tray icon, favicon, compact overlays, small UI surfaces
- Mono dark: light backgrounds, monochrome print, documentation
- Mono light: dark backgrounds, overlays, high-contrast UI
- Dark app icon: Windows shortcut, installer, Store-style listing
- Light app icon: light-theme contexts and promotional variants
- Hero banner: repository/social/header artwork

## Notes
These assets were generated from a consistent visual direction. For production trademark use, recreate the core logo as a deterministic vector master and run final name/logo clearance before release.
